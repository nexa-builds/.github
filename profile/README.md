# Nexa Builds

Ports, recomps, and handheld builds for retro games.

## Projects

### Ports for Dual Screen Android Handhelds

The following games are ported for Anbernic RG DS Plus running [GammaOS Nano](https://github.com/TheGammaSqueeze/GammaOSNext/releases). They might also work on other devices / OSes but compatibility is not guaranteed.

| Repository | Game | Features | Latest |
| :--- | :--- | :--- | :--- |
| [**zelda3-android-ds**](https://github.com/nexa-builds/zelda3-android-ds) | *A Link to the Past* | Game on upper panel, companion on lower panel | [v2.1](https://github.com/nexa-builds/zelda3-android-ds/releases/latest) |
| [**tmc-android-ds**](https://github.com/nexa-builds/tmc-android-ds) | *The Minish Cap* | Game on upper panel, companion on lower panel | [v1.3.1](https://github.com/nexa-builds/tmc-android-ds/releases/latest) |

No game data is distributed here. You'll need your own legally owned ROM to play.
